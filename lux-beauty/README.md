# لوکس بیوتی

فرانت‌اند صفحه مشتری سالن زیبایی لوکس بیوتی؛ یک صفحه با تب‌های خانه، خدمات، آرایشگران، نمونه کارها، درباره ما، نظرات و تماس. نسخه دسکتاپ و موبایل واکنش‌گرا، راست‌چین و فارسی.

## اجرا

```bash
cd lux-beauty
npm install
npm run dev
```

سپس مرورگر را روی [http://localhost:3000](http://localhost:3000) باز کنید.

## اسکریپت‌ها

- `npm run dev` — سرور توسعه
- `npm run build` — بیلد تولید
- `npm run lint` — بررسی ESLint
